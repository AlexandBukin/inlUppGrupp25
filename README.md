# Travel Route Visualizer

**Course Project (PROG2) - Group 25**  
**Authors:** Alexander, Luka, Maxime

## Overview

**Travel Route Visualizer** is an interactive application that allows users to create and visualize routes between cities. Users can **add, move, and remove cities**, as well as **create or delete connections** between them.

The application uses **Depth-First Search (DFS)** and **Breadth-First Search (BFS)** to find routes between selected cities and displays the complete path, including all intermediate stops.

## Features

- **Create, move, and delete cities**
- **Add and remove connections between cities**
- **Visualize travel routes on a map**
- **Find paths using DFS and BFS algorithms**
- **Save and load projects from text files**
- **Choose custom background images**

## Purpose

The project demonstrates the practical use of **graph data structures**, **graph traversal algorithms**, **file handling**, and **GUI development** in a travel planning and route visualization system.
